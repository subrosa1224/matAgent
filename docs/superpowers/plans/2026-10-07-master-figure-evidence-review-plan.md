# 待核对图证据实施计划

用户于 2026-10-07 回复“按文档实施”，书面设计已批准。writing-plans 技能在当前技能目录不可用，使用本常规计划，不安装额外技能。

依据：`docs/superpowers/specs/2026-10-07-master-figure-evidence-review-design.md`。

## 实施顺序

1. 安全底座：新增严格图证据契约、不可变图像/批次存储、授权来源渲染、文字确认/跳过/关闭服务，先编写失败测试再实现。任务字段兼容默认 disabled；不接生产工厂、不启用开关。验证来源、越界、重放、篡改、修订和统计输入不被修改。
2. 本地 OCR：独立适配器及资源限制，支持 unavailable 和手工转录；无远程图像传输、不安装软件。临时 spike 不直接作为生产实现。
3. 主控接续：新任务记录启用策略，提取与统计之间加入闸门；结构化操作使用会话锁和当前服务器引用，普通“继续”只展示核对入口。图证据仅进报告附录，旧任务及数据集保持。
4. 网页和 CLI：授权论文/页码选择、来源页与矩形、局部图/原始识别/修订文字、确认/跳过/完成按钮，调用共享服务。验证真实 UI 而非只加载页面。
5. 兼容与开发验收：离线回归、真实本地 PDF 核对、正常入口恢复及统计隔离。逐层记录验证范围；未实测的网页/正常链路保持未验收，45 条正式观察仍 NOT_RUN。

## 工作约束

- 不修改旧 PDF、矩阵、审核、数据库记录、冻结结果或 `.env`。
- 开关默认关闭，旧任务不随开关升级，已结束任务不自动重开。
- 不运行远程模型或扩大先前诊断许可；本地测试替身不计为真实模型成功。
- 每阶段保存测试及来源证据，保护文件检查失败即停止后续写入并查明原因。
- 不生成实验条件绑定、材料专业正确性或完整稳定验收已通过的结论。
