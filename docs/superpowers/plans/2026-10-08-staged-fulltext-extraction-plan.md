# 分阶段全文提取实施清单

依据用户已批准的 `../specs/2026-10-08-staged-fulltext-extraction-design.md`。
writing-plans、test-driven-development、verification-before-completion 技能当前不可用；
采用此显式清单和失败测试→最小实现→回归→真实验收流程，不再重复请求设计授权。

## 顺序与验收

1. 新增独立阶段契约及来源验证。先测试跨段 NTO3 定义与约82%性能、错误来源、
   串样、伪数值、损坏指数、表格错列；保持旧版矩阵验证不变。
2. 规划覆盖全部解析片段的小步骤，密集表格保留完整对应或显式待核对。
   模型最多12条记录、每请求最多2个指标、原文约3000字；不隐式裁掉正文。
3. 新增版本化追加式存储与独立任务引用。每阶段保存，复用核对任务、模型与来源；
   两次结构化尝试、共享预算、取消和真实失败有不同状态。
4. 样品清单→指标→既有条件定位/读取接口；条件单独验证值与适用关系。
   冲突和未知保留，不删除有效性能、不生成比较排名。
5. 新复合来源交接与显示适配；范围隔离，科学计数法只能来源明确后解析。
   新路径不能将新记录强制转换为旧版矩阵来绕开校验。
6. 在隔离目录，使用显式全文模型设置（若有）或已配置主模型，对第1篇真实PDF验证。
   记录模型、请求、各阶段保存情况、用户指标覆盖及不能比较的原因。
7. 第1篇达到设计验收后才扩展原10篇及部署；否则保留真实失败与已完成阶段，
   不切换正在运行的页面，不修改旧快照/原PDF/原会话。
