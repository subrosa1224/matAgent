# 主控图中文字核对使用说明

本版只核对图中文字，不确认实验条件、样品身份、测量终点或材料优劣。原始 OCR 与人工修订分别保存；图证据仅用于报告附录。

## 启用与兼容

功能默认关闭。启动主控前设置环境变量 `MASTER_FIGURE_EVIDENCE_REVIEW=true`，再初始化主控并创建新的科研任务。已存在的任务仍保持其原策略；旧报告不补写本步骤。本次实施没有修改 `.env`。

当前仍在运行的旧版 8510 服务不会自动变成新代码。本次验证使用独立、已停止的本地测试服务，不替换原页面。实际使用需按原启动方式重新启动新版本。

## 网页操作

全文详细提取完成后，新任务进入等待图中文字核对阶段。在对话区域展开“图中文字核对（可选）”，刷新并选择当前任务；有多个任务时必须明确选择。

1. 选择本任务已提取的授权论文和页码，点击“查看来源页”。
2. 在来源页依次点击区域的两个对角；第三次点击重新选择。坐标按服务器保存的原页图像尺寸转换，不能输入任意图片路径。
3. 填写人工图号 / 面板说明及文字类型，点击“本地识别所选区域”。
4. 对照局部原图，在修订框改正识别文字，再点击“确认文字”。原始识别不会被覆盖。没有本地 OCR 时可手工转录；系统保留 unavailable / failed 状态。
5. 不采用的图点击“跳过此图”。重新选区域会保留旧候选历史，不覆盖旧 OCR。
6. 点击“完成核对并继续”，恢复原主控分析并把报告放回对话。存在未决定图时会阻止继续；如需放弃，明确勾选“跳过所有尚未决定的图”或点击“跳过图证据并继续”。

“取消本地识别”会请求中止正在运行的本地处理。普通聊天中的“继续”“确定”“都正确”不会代替这些明确操作。

## 命令行

网页与 `materials-screen master figure-review` 共用任务核对服务、来源检查及会话锁。

先用 `show --conversation-id <会话> --task-id <任务>` 读取当前引用。写操作必须同时提供返回的 `--batch-id`、`--batch-sha256` 和自行指定的 `--operation-id`。

支持 `page`、`add`、`confirm`、`skip`、`close`、`skip-all`：

- `page` 指定 `--document-id` 与一基 `--page`。
- `add` 指定论文、页码、图号、文字类型；四次 `--region` 分别传 PDF 页面点坐标 x0、y0、x1、y1，不能使用网页屏幕坐标。可用 `--replace-candidate-id` 保留旧候选并替代。
- `confirm` 必须指定 `--candidate-id` 和 `--text`；`skip` 必须指定候选，不能提交修订文字。
- `close` 不会默许未决定候选；`--skip-remaining` 明确跳过剩余。`skip-all` 明确放弃全部本批图证据。

每次成功写操作都返回新引用。重复同一请求使用同一 operation-id 和完全相同内容；改变内容应刷新引用后使用新 operation-id。记录保存后而任务指针写入中断的同一操作可以恢复，不重复 OCR。

CLI 关闭批次不会自行调用模型。随后使用原配置的 `master ask --message 继续 --conversation-id <会话> --task-id <任务>` 接续；使用 Intern 的任务需明确保留 `--llm-provider intern` 等原运行参数。

## 失败与验收边界

来源校验失败、旧引用、越界区域、超长文字或资源超限都不能确认。损坏的图证据可以明确放弃；原 PDF 自身被修改或丢失时，原主控来源校验仍生效，可能需要重新提供原文件才能继续，不能通过图核对跳过 PDF 完整性检查。

报告中的 `text_verified` 仅表示当前操作者核对文字；`condition_binding_status` 始终为 `unbound`。部分报告仍为 partial，原测量的 pending 审核状态不升级。轴末端 180 分钟不能自动写成所有样品的测量时间。

本次开发回归及离线网页 / CLI 测试不等于真实模型完整链路验收，更不等于材料专业正确性验收。正式 45 条 NOT_RUN 记录保留不变。
