# LiteratureAgent P2 单篇档案抽取基线

> 状态：P2 已完成并通过验收  
> 日期：2026-08-21  
> 上位约束：`literature_agent_execution_baseline.md`

## 1. 阶段边界

P2 只完成文本型材料论文 PDF 的证据绑定单篇档案抽取。自动结果一律写入独立候选区并保持
`pending`；不读取或覆盖人工批准档案，不抽取 P3 实验矩阵，也不生成跨论文综合报告。

## 2. 正式能力

- 正式入口：`materials-screen literature dossier-extract --pdf <文件>`。
- 十二类独立任务：研究问题、创新、材料、制备、器件/样品制备、表征、结构、光学、
  性能、机理、局限和复现参数；不适用类别允许为空。
- 每类从全文分块中独立排序，截取关键词密集的原文窗口后进行严格结构化抽取。
- 每项保存 `document_id`、`chunk_id`、起止页、原文短引、分块 SHA-256、置信度、风险和
  `llm_extracted` 标记。
- 原文短引必须可回落到对应分块；只允许修复 PDF 断词或空格噪声，语义改写不能冒充原文。
- 中文摘要中的所有数字必须存在于同一条原文短引；否则内部先降级为原文并标记高风险，
  随后进入独立安全翻译步骤。
- 英文或安全降级摘要会进入独立批量翻译；译文必须包含中文且再次通过数字校验。翻译失败
  时显示中文“待人工核对”提示，绝不把英文原文塞进摘要字段。
- 自动候选保存在 `data/literature_dossier_candidates`，已批准档案位于另一目录，因而不会
  被自动抽取覆盖。
- `dossier-pending <document_id>` 按高、中、低风险顺序展示全部候选及原文；
  `--risky-only` 可隐藏低风险项。
- pgvector 不可用时，可直接从已授权 PDF 构造确定性临时分块；不会伪装为已经完成向量入库。

## 3. 兼容性修复

Intern API 当前拒绝连续两条 `system` 消息，旧 Provider 因而返回
`in prompt processing error`。适配层已把任务指令与 JSON Schema 合并为一条 system 消息，
并兼容代码围栏及思考文本包裹的 JSON。档案抽取默认使用同一服务的
`intern-s1-mini`，可由 `LITERATURE_EXTRACTION_MODEL` 覆盖，不改变主智能体模型。

## 4. 三篇金标盲测

生成候选时只读取 PDF，不读取人工档案；生成完成后才运行独立评测器与批准档案比较类别。

| 文档 | 候选数 | 类别召回 | 中文摘要 | 证据/原文可解析 | 无来源数字 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Nb-TiO2/TCNQ | 17 | 91.67% | 100% | 100% | 0 |
| 混合阳离子钙钛矿 | 24 | 83.33% | 100%（2 条已隔离） | 100% | 0 |
| 2025 骨诱导 CaP 生物陶瓷 | 13 | 81.82% | 100% | 100% | 0 |

加入核心完整度、档案叙述、通用去重、类别一致性过滤和单证据摘要重写后，类别宏平均
召回率为 **85.61%**，超过
P2 的 80% 门槛。结构化模型
输出存在波动，因此基线记录最新一次完整盲测的真实值，不选择性保留更高结果。评测命令为：

```powershell
uv run python scripts\evaluate_literature_p2.py
```

## 5. 人工验收结果

首轮人工评分为：TiO2 4/5、钙钛矿 3/5、生物陶瓷 4/5，平均 **3.67/5**。针对“第二、
第三篇信息不足且叙述不清”的反馈，已增加按十个核心栏目计算的完整度和按论文逻辑顺序
组织的证据安全叙述层；钙钛矿与生物陶瓷核心完整度均为 90%。第二轮评分为 TiO2 4/5、
钙钛矿 4/5、生物陶瓷 4/5，平均
**4.00/5**，且任一论文均不低于 3/5，P2 正式通过。

本次评分仅关闭 P2 阶段验收，不自动批准数据库中的 pending 候选，也不自动进入 P3。
