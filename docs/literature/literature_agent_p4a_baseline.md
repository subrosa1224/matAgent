# LiteratureAgent P4A 检索入口验收记录

> 状态：完成  
> 日期：2026-08-21  
> 范围冻结：仅实现候选文献发现，不包含 PDF 自动获取、全文解析、实验矩阵抽取或跨论文全文综合。

## 1. 用户能力

用户可通过一个自然语言主题调用统一检索入口。系统确定性扩写中英文材料概念与性能/工艺
术语，并检索 OpenAlex 和 Semantic Scholar。结果经过 DOI 优先、标题与年份兜底的跨源
去重，再按主题覆盖、摘要可用性与引用信息排序。

标准命令：

```powershell
uv run materials-screen literature search `
  "多孔磷酸钙生物陶瓷骨诱导结构孔隙率" `
  --year-from 2020 `
  --max-papers 10 `
  --show-abstract
```

支持重复 `--material`、`--year-from`、`--year-to`、`--max-papers`、
`--show-abstract` 和供程序消费的 `--json`。

普通输出包含标题、年份、DOI、作者、期刊/会议、引用数、摘要可用状态、文献入口、入选
原因与可选摘要预览；JSON 输出保留严格 Schema、Provider 溯源、检索时间和原始记录哈希。

## 2. 降级与边界

- 任一 Provider 限流或暂时失败时，保留另一来源的结果并明确显示 `degraded`，不伪装成
  双源成功。
- 两个 Provider 均失败时返回明确错误，不编造候选论文。
- `open_access_reported` 只表示数据源报告开放获取，不保证程序能够自动下载 PDF。
- 摘要只能用于候选筛选，不能替代全文证据或直接生成已批准实验事实。
- 查询快照保存到 `data/literature_queries/<query_id>`，相同请求可复现且避免重复消耗接口。

## 3. 验收结果

离线验收覆盖 Provider 映射、双源合并、DOI 去重、排序、查询扩写、快照复用、单源失败
降级和工具注册，共 8 项通过；Ruff 与定向 mypy 通过。

真实检索主题为“多孔磷酸钙生物陶瓷骨诱导结构孔隙率”，限定 2020 年以后并返回前 5 篇：

- OpenAlex 正常，5 个扩写查询合计返回 25 条原始记录；
- Semantic Scholar 触发公开接口限流，系统正确降级；
- 合并排序后返回 5 篇带 DOI、作者、期刊、引用数、入口和摘要的候选文献；
- 查询快照 ID：`lit-fd4e0b5008cb48fd801bdc74`。

P4A 验收通过。检索相关性的 10 主题 Recall@20 正式评测仍属于 P5；本阶段不以单个真实
主题的排序结果代替专家相关性评测。

## 4. 中文主题相关性修正

真实用户测试发现初始排序会让高引用但仅宽泛相关的论文进入前列。2026-08-21 完成
确定性相关性修正：

- 扩写后的英文材料、性能和工艺概念共同参与排序，不再只按原始英文字符评分；
- 材料短语与研究目标采用分类门槛，主题同时要求成骨和孔结构时必须分别命中；
- 标题匹配权重高于摘要，引用量降为同等相关性下的弱排序信号；
- `osteogenic`/`osteoinductivity` 与 pore/porous/porosity 使用受限词族匹配；
- 每个材料同义词形成独立检索式，避免把所有近义词堆入同一查询造成零召回；
- 未达到门槛的记录不再用高引用量补足固定数量，并明确报告空结果。

同一生物陶瓷主题的最终真实验收从宽泛候选收敛为 2 篇同时满足材料、成骨和孔结构
条件的论文；查询快照为 `lit-197204675adc755e008fa212`。定向离线回归 9 项通过，
Ruff 与 mypy 通过。严格过滤可能返回少于 `--max-papers` 的结果，这是预期行为，不再用
低相关论文凑数。

用户随后反馈严格门槛导致结果过少且偏旧。检索排序继续升级为
`unified-v5-tiered-recency`：

- `core`：材料、性能、工艺/结构等主题维度全部命中；
- `high`：缺少一个维度，但材料与主要研究目标仍明确相关；
- `extended`：材料体系相关，作为扩展阅读单独标记；
- `--sort balanced`（默认）兼顾层级、相关性和近三年新近性；
- `--sort recent` 在同一相关层级内优先新论文；
- `--sort relevance` 不加新近性奖励；
- 每个扩写查询扩大候选池后再统一去重分级，最终不超过 `--max-papers`。

同一主题的最终真实验收从 2 篇恢复为 10 篇，OpenAlex 原始候选 139 条。前列包括孔几何、
不同孔隙率、TPMS/支杆结构与成骨性能研究；每篇均显示相关层级、命中概念和相关性分数。
验收快照为 `lit-4e32e067e4556be24eb171d1`。Semantic Scholar 本轮仍因公开接口限流
降级，因此配置 S2 Key 后仍需再次验证双源覆盖。
