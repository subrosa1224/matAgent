# LiteratureAgent P3 通用实验矩阵实施基线

> 状态：P3 进行中  
> 日期：2026-08-21  
> 上位约束：`literature_agent_execution_baseline.md`

## 1. 阶段目标

从文本型材料论文的正文证据中自动恢复可比较的实验设计，并独立核验摘要作者主张。P3
不实现跨论文综合或端到端主题编排；这些属于 P4。

## 2. 固定数据流

```text
证据分块
  → 实验相关分块召回
  → 实验组与测量候选抽取
  → 原文、页码、哈希、数值和单位校验
  → 确定性组间比较
  → 摘要主张抽取
  → 正文测量/比较核验
  → pending 候选与 warning
  → 人工审核
```

## 3. 本阶段交付物

- 通用矩阵抽取入口，不使用三篇论文专用脚本。
- 实验组包含角色、材料、变量、制备/测试条件及证据。
- 测量包含指标、原始数值文本、解析数值、单位、不确定性、样本量及证据。
- 比较只由已校验的测量确定性生成；不让 LLM 计算变化量。
- 摘要主张保持 `pending`，并标记支持、部分支持、矛盾或不可核验。
- 缺失表格、跨页表格、仅图中可见数值产生明确 warning。

## 4. 验收门

- 三篇金标数值精确率不低于 95%。
- 关键实验组召回率不低于 80%。
- 单位保真率不低于 95%。
- 无证据记录进入 `approved` 的数量为 0。
- 摘要主张不得直接生成可信知识边。

## 5. 当前实施顺序

1. 加固证据契约：变量、条件、数值、单位、不确定性、页码和哈希均可校验。
2. 建立通用自动候选抽取器和候选隔离区。正式入口为
   `materials-screen literature matrix-extract <document_id>`；只写入 `pending`。
3. 确定性生成比较并完成摘要—正文核验。
4. 建立三篇金标的独立评测器，运行自动与人工验收。

P3 未通过第 4 项前保持“进行中”，不进入 P4。

## 6. 当前实现进度

- 通用入口已经能从已索引文档生成实验组、测量、确定性比较、摘要主张和正文核验链接。
- 比较只连接指标与单位一致的对照/参考组和处理组；变化量由程序计算。
- 主张核验要求指标匹配，并根据数值或方向标记为 `supported`、
  `partially_supported`、`contradicted` 或 `not_verifiable`。
- 所有记录与核验链接保持 `pending`；摘要主张不会直接进入可信知识边。
- 当前 LiteratureAgent 单元回归为 43 项通过；Ruff 与 P3 定向 mypy 通过。

剩余工作仅为三篇金标的独立 P3 评测、误差修正和人工验收，不提前进入 P4。

## 7. 首轮真实盲测记录

独立评测器已经实现，自动候选只驻留内存，评分完成前不写数据库；approved 金标仅在自动
抽取结束后载入。首轮和第二轮暴露了 PDF 引文噪声、列表型条件和长输入超时，安全门均将
不合格候选拒绝，自动 approved 数保持 0。

TiO2 最近一次完整单篇结果为 2 个预测组、0 个可接受测量；尚未通过 P3 门槛。主要原因是
关键证据批次超时、模型未绑定 measurement `group_key`，以及评测归一化不足。本轮已继续
完成以下通用修正：

- 每个证据批次失败后重试一次，最终失败只隔离该批次。
- 程序可跨 chunk 重定位包含全部变量、条件、数值和单位的证据。
- 缺失 `group_key` 时仅在证据能唯一指向一个已校验组时补链；歧义时仍拒绝。
- 百分号空格差异纳入金标匹配归一化。

这些修正已通过定向测试，但尚未重新完成三篇真实盲测，因此 P3 继续保持“进行中”。

70 % 在 7 天时的 COL-I、OPN 结果均能被完整绑定。裁决以独立 JSON 保存，未把自动候选
直接写成数据库 approved 记录。
