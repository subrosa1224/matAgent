# RA-0 晶态无机材料 Benchmark V1 基线

> 路线：RA-0A / RA-0B  
> 日期：2026-09-02  
> 状态：RA-0A 工程银标完成；RA-0B 专业金标审核未完成  
> 对应路线：`docs/research/end_to_end_research_task_plan.md`

## 1. 本阶段目标

RA-0A 只建立测评资产和改造前基线，不实现新的项目编排器、属性能力门、材料身份解析器、
跨数据库适配器或界面。

本阶段用于回答：

1. 当前系统已经可靠完成什么；
2. 当前系统不能完成什么；
3. 后续改造是否真的提升了端到端材料筛选能力；
4. 哪些测试结果只是自动银标，哪些已经获得人工专业审核。

## 2. 已冻结的数据

Benchmark 当前冻结 300 条 Materials Project 氧化物记录。记录来自三个已有本地查询快照，
数据库版本均为 `2026.04.13`：

- `query-0fcc4e292c4d4896ab51a8846951d347`：宽条件含氧材料快照；
- `query-e7798308f9154323b28e4dc58693e3bf`：稳定宽带隙氧化物快照；
- `query-6e2ecc32641b4adda78906dd50f834f2`：26 条 Fe2O3 多晶型快照。

生成器保留所有宽条件氧化物和 Fe2O3 边界记录，再用稳定宽带隙氧化物补足 300 条。最终
记录按 `material_id` 排序并去重，不保存庞大结构正文，只保留筛选和身份测评所需字段：

```text
material_id / formula_pretty / elements / chemsys
band_gap_ev / energy_above_hull_ev_atom / formation_energy_ev_atom
density_g_cm3 / is_metal / is_gap_direct / is_stable
theoretical / deprecated / crystal_system / spacegroup
source_query_ids / database_version
```

源查询 metadata、原始 records 文件和冻结快照均记录 SHA-256。生成过程只读取本地快照，
不调用外部 API。

## 3. 已建立的测评层

### 3.1 确定性筛选案例

已建立 15 个案例，覆盖：

- 必含和排除元素；
- 带隙、能量高于凸包和密度范围；
- 稳定性、金属/非金属、理论来源和废弃标志；
- 晶系和空间群；
- Fe2O3 多晶型；
- 目标值排序和字段升降序；
- 零结果且不得自动放宽约束。

每个案例保存总匹配数、完整材料 ID 集合、Top-K 顺序和预期状态。答案由独立、短小、
可审阅的参考逻辑从冻结快照生成，未调用生产 `FilterService` 或 `RankingService`。

### 3.2 材料身份边界

已建立 20 对身份案例：

| 类型 | 数量 | 当前等级 |
|---|---:|---|
| 相同来源、相同 material ID | 5 | 确定性标签 |
| 相同化学式、不同空间群 | 10 | 待材料专业审核 |
| 相同化学体系、不同化学式 | 5 | 确定性边界标签 |

不同空间群足以证明不能只按化学式直接合并，但并不足以完成严格结构同一性判断，因此这
10 条没有被冒充为正式金标。

### 3.3 文献种子证据

已登记 5 篇现有人工批准 dossier，并冻结 dossier 与审核文件哈希：

- Nb 掺杂 TiO2 光伏论文；
- 2025 磷酸钙生物陶瓷论文；
- 混合阳离子钙钛矿光伏论文；
- 两篇已批准生物陶瓷 dossier。

这些文献已经通过原 LiteratureAgent 审核，但“获得批准”不代表自动适用于新的筛选金标。
它们当前仅是种子证据，仍需逐任务判断材料身份、属性和实验条件可比性。

另已登记 3 篇任务专属开放全文线索，但没有将其计入批准数量：

| DOI | 用途 | 当前状态 |
|---|---|---|
| `10.1039/D2CC03168J` | ε-Fe2O3 喷雾干燥实验合成 | 已归档并生成银标档案，待专业审核 |
| `10.1038/srep15091` | ζ-Fe2O3 高压形成及卸压后保留 | 已归档并生成银标档案，待专业审核 |
| `10.1038/s41467-018-06682-4` | 跨材料亚稳性边界；不能证明具体候选已合成 | 已归档并生成银标档案，待专业审核 |

用户已提供三篇本地 PDF。系统已冻结文件哈希，并从每篇提取 5 条带页码、原文片段和页面
文本哈希的 `manual_pilot` 银标档案。由于尚未完成材料专业审核，这些档案保持 `pending`，
不能进入正式报告或计入批准数量。

### 3.4 端到端任务草案

已建立三个任务合同草案：

1. 稳定宽禁带氧化物候选筛选；
2. Fe2O3 同化学式多晶型比较；
3. 亚稳但具有实验合成证据的候选。

三个任务均已绑定数据库标准答案和禁止越界的 Claim 检查，但尚未全部获得任务专属文献
和材料专业人员批准，因此状态保持 `draft_pending_*`。

## 4. 改造前自动基线

使用当前生产 `ScreeningRequest` 和 `FilterService` 对可精确表达的案例进行离线比较，
得到：

| 指标 | 当前结果 |
|---|---:|
| 筛选案例总数 | 15 |
| 当前合同可表达的过滤案例 | 14 |
| 过滤结果完全一致 | 14/14（100%） |
| 不支持的过滤案例 | 1 |
| 任务专属排序案例支持 | 0/15 |
| 身份关系案例支持 | 0/20 |
| 端到端任务完成 | 0/3 |

不支持的过滤条件是 `is_gap_direct`。记录中已有该字段，但当前 `ScreeningRequest` 没有将其
作为硬筛选条件。

当前 `RankingService` 使用固定的半导体评分组成，不能精确表示 Benchmark 中按密度、
能量高于凸包、带隙目标或 material ID 指定的不同排序合同。因此本阶段没有用近似排序
冒充通过。

当前还没有项目级材料身份解析器和 `ScreeningOrchestrator`，所以身份关系和端到端任务
基线均为 0。这是能力缺失，不是现有单 Agent 运行失败。

### 4.1 回归与代码质量记录

## 5. CSV 功能兼容门禁

现有 DataAnalysisAgent 的 CSV/JSON/XLSX 上传、数据质量、描述统计、统计检验、图表、
不可变清洗和报告功能必须保留。RA 后续阶段每次全量回归必须继续运行现有数据分析测试。

两种入口保持独立：

```text
独立上传数据并询问统计问题 → DataAnalysisAgent
材料筛选项目中的候选表或实验表 → 作为独立项目证据接入
```

非材料 CSV 可以继续独立分析，但不自动升级为晶态无机材料筛选项目。

## 6. 当前门禁缺口

RA-0A 已满足工程开发基线；RA-0B 尚不能标记完成，原因是：

1. 当前有 5 篇批准种子 dossier，另有 3 篇任务专属全文已归档并生成待审银标档案；后 3 篇尚未获得专业审核，因此仍未达到 8 篇批准门槛；
2. 金标 B 和 C 仍缺少任务专属的已审核全文证据；
3. 10 条多晶型身份标签仍需材料专业审核；
4. 三个端到端任务的预期 Claim、候选等级和验证建议仍需专业批准；
5. 当前 300 条快照以氧化物为主，不能证明全部晶态无机材料泛化；
6. 全量离线测试已通过，但全仓库 Ruff 和 mypy 仍有本次变更前已存在的问题。

以上缺口保存在 `manifest.json`，不会为了显示阶段完成而被隐藏。
