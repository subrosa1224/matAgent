# RA-1 筛选合同、属性注册与能力门基线

> 日期：2026-09-02  
> 状态：工程验收完成  
> 前置条件：RA-0A 工程银标完成；RA-0B 专业金标并行待审  
> 对应路线：`docs/research/end_to_end_research_task_plan.md`

## 1. 本阶段完成范围

RA-1 建立了运行材料筛选项目前必须通过的确定性合同和门禁，不执行数据库查询、文献
综合或最终报告。新增能力包括：

1. 项目合同：研究问题、应用背景、晶态无机材料范围、筛选/排序/报告条件和有界资源上限；
2. 属性注册：规范属性 ID、中文名称、显式别名、规范单位、值类型、来源角色、允许用途、
   缺失值策略和可比性说明；
3. 能力判断：返回 `supported`、`partial` 或 `unsupported`，并逐条件列出阻塞原因；
4. 确认卡：向后续问答界面提供用户可读的已支持项、阻塞项、缺失值声明和确认提示；
5. 项目存储：保存当前状态、不可变 revision 和逐次决策日志；
6. 状态门禁：只允许合法状态转换，当前 revision 未确认时不能开始运行。

## 2. 当前属性边界

当前注册表只登记已有 Materials Project 快照和数据库适配能力能够明确解释的基础属性：

- 计算带隙、凸包上方能量、形成能和晶体密度；
- 数据库稳定标记、金属性、理论结构标记；
- 空间群编号、晶系；
- 化学式和元素集仅作为报告信息；
- 直接带隙标记已经登记，但由于现有生产筛选合同尚不能执行该硬过滤，能力门返回
  `partial` 并阻止运行。

击穿强度、成本、毒性、催化活性、力学性能等未登记属性不会被自动改写成带隙、稳定性
或其他近似指标。新增属性必须先补齐定义、来源、单位、缺失处理、可比性和相应测评。

## 3. 科学与执行保护

- 每个条件必须显式选择缺失值策略；
- 单位不一致、数值类型不正确或非有限数值会被阻塞，不做静默换算或填补；
- 硬过滤不能使用排序操作符，排序也不能伪装成硬过滤；
- 数据库计算带隙不会被描述为实验光学带隙或击穿强度；
- `is_stable=False` 不会被解释为实验上不能合成；
- 化学式相同不会在本阶段被解释为结构或物相相同；
- 项目从草稿到待确认、已确认、运行和结束均受显式状态机约束；
- 合同修改必须产生新 revision；旧 revision 覆盖、终态重开和未确认运行均被拒绝。

## 5. 保留能力与限制

`materials_screening.research` 包中，后续通过只读适配器接入原有三个子 Agent。

核验编排、候选分级或 DOCX 报告；因此当前不能宣称已经完成端到端科研任务。
