## 1. 问题定义

DA-8 解决了功能发现和基础交互，但当前系统仍是字段级通用 EDA：缺少研究问题、实验
设计、变量角色、实际意义和证据强度；报告以分析记录和 Markdown 为中心，不适合多数
非计算机领域科研人员。

DA-9 的目标不是自动替代科研判断，而是把确定性计算组织成可审阅的科研分析链：

```text
研究问题 → 实验设计与变量角色 → 分析方案 → 统计证据
         → 科研解释 → 局限与下一步实验 → Word/PDF 交付
```

## 2. 边界

- 首个领域配置为材料科学实验数据，同时提供跨学科通用配置；
- 所有数值、检验、区间和图表仍由确定性程序产生；
- 不由大模型口算统计量，不把相关性写成因果关系；
- 未确认响应变量、分组、配对/重复测量结构时不自动执行推断检验；
- 自动推荐必须说明依据并允许用户修改；
- Markdown/JSON 保留为审计底稿，默认用户报告改为 DOCX；PDF 作为可选发布格式。

## 3. 实施顺序

### DA-9.0：科研任务合同与基线

建立 `ScientificAnalysisBrief`，至少包含：

- 研究问题和领域配置；
- 观测单位、实验设计（独立/配对/重复测量）；
- 响应变量、分组/处理变量、协变量和标识字段；
- 假设、显著性阈值、实际意义阈值；
- 单位、数据来源和用户确认状态。

验收：未确认关键角色时，Agent 只澄清、不运行推断检验。

### DA-9.1：对话式科研任务建模

- 上传后先提供数据画像，再询问研究目标；
- 根据字段名、类型和基数提出候选角色，但不擅自确认；
- 采用逐步气泡选项确认响应变量、分组变量和实验设计；
- 在会话中显示一张简洁的“当前研究设定”，允许修改。

验收：分组问题必须先确认比较指标；配对/重复测量必须确认配对 ID。

### DA-9.2：设计感知的分析方案

- 两组：Welch t / Mann–Whitney，并报告效应量与区间；
- 多组：ANOVA / Kruskal–Wallis，显著后提供受控事后比较及多重校正；
- 配对数据：配对 t / Wilcoxon；
- 连续变量：相关性与带诊断的线性回归；
- 统一输出样本量、缺失处理、假设检查、效应量、不确定性和适用边界；
- 明确区分统计显著性与实际意义。

验收：方法由研究设计和用户选择共同确定，不按第一列自动推断。

### DA-9.3：科研解释与建议层

- 将统计对象转换为“回答了什么、发现了什么、证据多强、不能说明什么”；
- 对无显著结果使用“证据不足”，不写成“完全相同”；
- 结合效应量、区间、样本量和质量问题生成证据强度说明；
- 输出可执行的复核、补样、验证实验和数据治理建议；
- 材料领域配置识别温度、压力、组成、密度、硬度、电导率、孔隙率等常见角色，
  但不臆造机理。

验收：主要结论使用普通科研语言，内部 ID 和原始 JSON 仅进入附录。

### DA-9.4：面向科研人员的 Word/PDF 报告

默认 DOCX 结构：

1. 标题、研究问题和数据来源；
2. 一页式摘要与关键结论；
3. 实验设计和分析方案；
4. 数据质量与可用性；
5. 主要结果、效应量、区间和图表；
6. 科研解释、局限和下一步建议；
7. 方法与可复现性附录。

要求：中文正文、可读表格、图表标题与注释、页眉页码；内部 ID 不出现在摘要和正文；
DOCX 必须完成渲染和逐页视觉检查。PDF 由同一已验收 DOCX 转换。

验收：非计算机背景用户无需阅读 Markdown/JSON 即可理解结论和限制。

### DA-9.5：领域泛化与最终门禁

- 领域词汇通过 profile 配置，不把材料字段硬编码进统计核心；
- 用质量问题、分组实验、材料属性三套数据建立科研叙事金标；
- 增加无显著差异、强效应小样本、假设失败、多重比较等反例；
- Ruff、mypy、报告渲染、数据分析、统一 UI 和全量离线回归；
- 建立 `da9_scientific_workflow_baseline.md`。

## 4. 变更控制

1. 严格按 DA-9.0～DA-9.5 顺序实施；
2. 每阶段测试通过后再进入下一阶段；
3. 不以“自动化”为理由跳过关键研究设定确认；
4. 计算结果与自然语言解释分层，解释不得改写原始数值；
5. 默认报告面向科研人员，审计信息进入附录；
6. 已有 CSV/JSON/Markdown 导出保持兼容；
7. 不修改 DA-9 范围外的用户文件和历史功能。
