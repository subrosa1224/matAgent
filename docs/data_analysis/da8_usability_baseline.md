# DA-8 DataAnalysisAgent 可用性验收基线

> 日期：2026-09-01  
> 对应计划：`da8_usability_plan.md`

## 1. 已交付能力

- 提供质量问题、分组实验、材料属性三套可直接上传的演示 CSV；
- CSV、JSON、XLSX 上传后自动执行只读 EDA，并保存 Dataset/Analysis ID；
- 统一页面展示数据规模、字段画像、质量提示和有界预览；
- 上传后在助手聊天气泡内提供自然语言问答选项，选择和答案均保留在对话流中；
- 系统自动推荐字段，独立专业参数面板默认折叠，空图表和空下载区不再占据页面；
- 用户仍可通过高级表单执行描述统计、相关性、六类统计检验、六类图表、报告和导出；
- 提供按键去重入口，清洗结果写入新的不可变数据集，原始数据保留；
- 结果中心支持统计文本、PNG 预览和报告/数据文件下载；
- 离线 mock 路由覆盖八个白名单工具；
- 材料数据库查询快照和已审核文献实验矩阵可在页面中显式导入；
- XLSX 只读取首个工作表，并复用已有文件、行列、单元格及表头限制。

## 2. 安全边界

- 自动 EDA 只读，不自动执行清洗或显著性检验；
- 不向模型或普通页面暴露内部路径；
- 不执行任意 Python、SQL、Shell、Notebook 或动态表达式；
- `.xls`、`.xlsm`、混合附件和超限工作簿关闭失败；
- 跨 Agent 来源保留来源标签，不把数据库计算值与文献测量值混为同一体系。

## 3. 验收路径

1. 上传 `quality_issues_demo.csv`，确认自动显示重复、缺失、常量和离群提示；
2. 选择 `sample_id` 执行按键去重，确认 12 行变为 11 行且原数据仍为 12 行；
3. 上传 `grouped_experiment_demo.csv`，执行分组描述、Welch t、散点图和报告下载；
4. 上传 XLSX，确认仅首个工作表进入自动 EDA；
5. 输入材料查询 `query_id`，导入后确认来源为 `materials_database`；
6. 使用 mock 模型分别触发八个工具意图，确认均路由至固定白名单参数。
