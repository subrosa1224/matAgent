# DataAnalysisAgent 使用指南与限制

## 1. 启动

```powershell
uv sync --extra workflow --extra web-ui --extra analysis
uv run materials-screen master ui
```

在统一页面选择“自动判断”或“数据分析”，上传 `.csv` / `.json` / `.xlsx`。CSV 必须为
UTF-8（允许 BOM）；JSON 顶层必须是对象数组，不接受嵌套对象或数组；XLSX 仅读取首个
工作表，不接受带宏工作簿。

上传成功后系统会自动给出只读 EDA，包括规模、字段类型、缺失/重复/常量等质量提示、
数值描述统计以及条件满足时的 Pearson 相关摘要。自动步骤不会清洗数据或运行显著性
检验。

## 2. 常用请求

```text
检查我上传的数据质量，不要修改数据。
按 method 分组，统计 hardness 的均值、中位数和标准差。
分析 temperature 与 conductivity 的 Spearman 相关性。
用 Welch t 检验比较 A、B 两组 hardness，并报告效应量和置信区间。
删除 sample_id 重复项，用各组中位数填补 conductivity，保存为新数据集。
生成 temperature-conductivity 散点图和 Markdown 报告。
```

也可以完全不写提示词。上传后，助手会在 EDA 对话气泡底部给出自然语言问题选项；
点击后，该问题和分析答案会继续写入同一聊天记录。后续按钮会根据刚完成的分析缩减并
改变，不会重复展示固定菜单；报告完成后快捷追问自动结束。系统会自动推荐字段；字段
表、原始预览和专业参数统一收进默认折叠的“数据分析工具（可选）”：

“比较不同组”不会擅自选择第一个数值列。助手会先说明识别出的分组字段，再在气泡内
追问需要比较的指标。确认研究问题、实验设计、变量角色、单位和实际意义阈值后，页面
先展示推荐分析方案；用户点击“开始分析”才执行计算。两组可选 Welch t 或
Mann–Whitney，多组可选单因素 ANOVA 或 Kruskal–Wallis；总体显著时执行 Holm 校正的
受控事后比较。科研 Word 报告只有在研究设定确认并完成分析后才生成。

分析完成后，对话先显示普通科研语言摘要，包括直接回答、证据强度、差异方向与区间、
实际意义、方法前提、不能说明什么和下一步建议；统计方法、p 值、效应量及分析记录进入
后续“统计明细”。无显著结果统一表述为“证据不足”，不会写成“各组完全相同”；未经
实验设计支持时只表述差异或关联，不自动生成因果结论或材料机理。

- 一键 EDA、描述统计、相关性和显著性检验；
- 六类图表、科研 Word 报告及 CSV/JSON 下载；Markdown/JSON 保留为审计底稿；
- 选择键字段后去重，并创建新数据集，原始数据不被覆盖；
- 输入材料查询 `query_id` 或已审核文献 `document_id`，导入后执行只读 EDA。

统计检验不会由描述统计自动触发。清洗、绘图、报告和导出仍必须点击按钮或明确提出。

## 3. 演示数据

`examples/data_analysis/` 提供三套开箱即用的数据：

- `quality_issues_demo.csv`：测试重复、缺失、常量和离群候选；
- `grouped_experiment_demo.csv`：测试分组描述、Welch t、ANOVA、相关性和绘图；
- `materials_properties_demo.csv`：测试材料属性描述、筛选思路和散点图。
- `paired_experiment_demo.csv`：测试配对 t、Wilcoxon 和不完整配对处理；
- `repeated_measures_demo.csv`：测试 Friedman、Kendall's W 和 Holm 事后比较。

建议先上传 `grouped_experiment_demo.csv`，再依次点击“描述统计”“显著性检验”“生成
图表”和“生成报告”，可在几分钟内覆盖主要功能。

## 4. 连续对话

页面保存当前 `dataset_id` 和 Master conversation ID，因此可以继续说“检查刚才的
缺失值”或“把上一次统计生成报告”。清除附件会移除当前附件和 dataset 引用，但
不会删除已经登记的数据集、分析结果或报告。

## 5. 跨 Agent 数据来源

- Materials Project 查询结果必须先保存为 `query_id` 快照，再转换成只含结构化
  材料字段的数据集；
- 文献数据只接受人工审核为 `approved` 且带 chunk/page 证据的实验矩阵；
- 数据分析结果回查 Materials Project 时，只传最多 100 个合法、去重的 `mp-*` ID；
- Master 按“用户数据 / 材料数据库 / 文献实验矩阵 / 数据分析”分区展示，禁止把
  文献测量值与数据库计算值混写成同一测量体系。

## 6. 安全与资源上限

- 单文件默认不超过 50 MB、100,000 行、500 列和 5,000,000 个单元格；
- 模型看不到内部文件路径、完整原始大表、API Key 或异常栈；
- 不支持任意代码、SQL、Shell、Notebook、插件脚本或动态表达式；
- 原始数据不可覆盖，清洗只生成带父子链的新数据集；
- CSV 导出对 `= + - @` 开头的文本做公式注入防护；
- 图表类型固定为直方图、箱线图、散点图、折线图、柱状图和相关热力图。

## 7. 当前限制

- 不支持旧版 `.xls`、带宏 `.xlsm`、Parquet、数据库直连、流式大数据或嵌套 JSON；
- 当前仅支持带残差诊断的单预测因素线性回归；不支持多元/非线性回归、机器学习、
  时间序列预测或因果推断；
- 文献矩阵不自动换算单位；同一指标出现多种单位时会给出警告；
- 小样本、常量列、零方差、空组、严重缺失或方法不适用时返回结构化错误，不产生
  伪统计结果；
- 相关性只能表述为关联，不能表述为因果关系。
