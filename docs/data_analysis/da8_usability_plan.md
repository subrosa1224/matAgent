# DA-8 DataAnalysisAgent 可用性增强计划

> 日期：2026-09-01  
> 状态：已完成  
> 前置基线：DA-0～DA-7 已验收

## 1. 目标

把“工具已经存在”转化为“普通用户能够发现、配置并拿到成果”。本阶段不增加任意
代码执行、自动因果推断或黑盒建模能力，不放宽 DA-0～DA-7 的数据和来源边界。

## 2. 实施顺序

### DA-8.0：使用率基线与演示数据

- 固化当前功能入口和主要阻塞点；
- 增加质量问题、分组实验、材料属性三套 UTF-8 演示 CSV；
- 为演示数据提供预期任务清单。

验收：三套数据可直接上传，分别覆盖质量、统计/绘图和材料字段场景。

### DA-8.1：上传即得的一键 EDA

- CSV/JSON/XLSX 登记后自动执行结构检查、质量评估和数值描述统计；
- 数值字段不少于两个时生成相关性摘要；
- 自动步骤只读，不自动清洗或运行显著性检验；
- 结果和 analysis ID 写入 UI 会话状态。

验收：mock 模式无需网络即可完成上传到 EDA 的闭环。

### DA-8.2：数据集面板与操作表单

- 展示当前数据集、规模、字段类型、缺失率、质量问题和有界预览；
- 字段选择使用下拉/多选，不要求用户手写列名；
- 提供描述统计、相关性、显著性检验和六类图表的显式表单；
- 所有表单仍调用确定性领域服务并保留稳定 ID。

验收：用户不输入提示词也能执行主要分析；非法组合返回可恢复错误。

### DA-8.3：结果中心与完整 mock 路由

- 统一展示统计表、图表预览、报告和下载文件；
- mock 路由覆盖八个白名单工具的明确意图；
- 连续会话可复用 Dataset、Analysis、Plot 和 Report ID；
- 普通页面不显示内部路径。

验收：八类工具至少各有一条离线验收路径。

### DA-8.4：跨 Agent UI 与 Excel

- 在统一页面提供 Materials Project query ID → 数据分析入口；
- 提供已审核文献实验矩阵 → 数据分析入口；
- `.xlsx` 仅读取首个工作表，执行与 CSV/JSON 相同的规模和单元格校验；
- 混合附件、宏文件和超限工作簿关闭失败。

验收：三类来源在结果中心保持独立标记；CSV/JSON/PDF 路由无回归。

### DA-8.5：最终门禁

- 更新 README、使用指南和限制；
- Ruff、mypy、数据分析、Master、统一 UI、数据库 UI、文献 UI 定向回归；
- 建立 `da8_usability_baseline.md`。

## 3. 变更控制

1. 严格按 DA-8.0～DA-8.5 顺序实施；
2. 每个阶段先测试再进入下一阶段；
3. 自动 EDA 只允许只读操作；
4. 变换、检验、绘图、报告和导出仍须用户显式触发；
5. UI 不保存或显示内部路径；
6. Excel 支持不得绕过现有大小、行列、单元格和类型限制；
7. 已有用户改动保持不变，只做最小补丁。
