# 导师沟通页视觉规范

## 视觉来源

参考用户提供的“保证科研可信性的机制”PPT：白色底、低饱和紫蓝主色、浅灰结构面、深色正文。保留其科研汇报气质，但减少圆形装饰和长段落。

## 色彩

- 主色：`#656DB2`，用于标题、流程节点和重点数字。
- 深色：`#22263A`，用于正文和表格标题。
- 辅助紫：`#969CCD`，用于次级节点与边框。
- 浅紫底：`#EEF0FA`，用于提示区和当前阶段。
- 浅灰底：`#F5F6F8`，用于分区背景。
- 成功色：`#287A63`，仅用于“已完成/可进入下一步”。
- 警示色：`#A36130`，仅用于“待专家复核/不得越过”。
- 白色：`#FFFFFF`，作为主背景。

## 字体与字号

- 中文字体：`Microsoft YaHei`、`PingFang SC`、`Noto Sans CJK SC`、sans-serif。
- 大标题：40–52px，700。
- 分区标题：28–34px，700。
- 正文：18–20px，行高 1.75。
- 表格与标签：15–17px。
- 关键数字：32–44px，700。

## 图形语言

- 主要结构使用直线、细边框、编号和时间轴，不使用装饰性插画。
- 圆角控制在 6–14px；不用大面积胶囊按钮。
- 阴影非常轻，仅用于固定导航和重点结论。
- 图标以文字编号和简单 CSS 几何标记替代，避免依赖网络资源。

## 布局

- 内容最大宽度 1280px，适配导师投屏和普通笔记本。
- 页面为纵向单页，顶部提供锚点导航。
- 每一部分先给一句结论，再给图表或表格。
- 打印时移除导航和交互控件，适配 A4 横向或浏览器导出 PDF。

## 语气

- 直接、审慎、可核查。
- 明确区分“已完成”“正在做”“计划做”。
- 不把专家数据称为训练集；首批 5 个任务定位为系统跑通、规则建立和金标种子。

## 明确不采用

- 紫粉渐变、发光效果、玻璃拟态。
- 虚构统计数据或成功率。
- 过多图标、卡片和动画。
- 需要联网才能显示的字体、图片或脚本。
