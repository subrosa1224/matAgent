# 材料多Agent系统总览页设计方案

## 目标

用一个可直接投屏和打印的单页HTML，解释项目定位、系统架构、真实用户流程、各模块作用、当前进度、创新位置和数据到微调的关系。

## 受众

- 材料专业合作人员；
- 项目指导与评审人员；
- 需要理解系统边界的非计算机背景研究人员。

## 信息结构

1. 项目定位与边界；
2. 当前系统架构；
3. 各Agent职责；
4. 真实用户使用流程；
5. 文献全文获取节点；
6. 数据和证据如何流动；
7. 系统最终输出；
8. 当前实现状态；
9. 三项创新的目标位置；
10. 研发专家流程与真实用户流程区别；
11. 数据到微调的路线。

## 视觉

复用现有紫蓝科研汇报风格。白底、低饱和紫蓝主色、浅灰分区；以文字、表格和CSS流程图为主，不使用外部图片、字体或脚本，不出现“导师”字样。

## 事实边界

- 当前已有Master和三个子Agent的工程基础；
- RA-0A、RA-1、RA-2、RA-3已形成工程基线；
- RA-0B专业金标仍待完成；
- 当前研究编排主要到证据准备阶段；
- RA-4至RA-6以及三项创新未完整实现；
- 约5000条SFT数据是后续目标，不是现有数据量；
- 文献全文RAG在手动文献流程中已有基础，但尚未完全接入Master自动编排。

## 输出

`outputs/advisor_briefing/material_agent_system_overview.html`
