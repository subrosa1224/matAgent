# 模型配置统一：本地修复

本轮按已确认范围，只修复配置读取并做离线验证。没有修改实际 `.env`、密钥或
科研数据，没有连接实验室服务，没有发送论文，也没有重启当前网页。

## 已修复

文献助手原先只使用 `AgentSettings`，可能忽略共享的 `INTERN_BASE_URL`、
`INTERN_MODEL`、`INTERN_THINKING_MODE`，继续使用旧服务。现通过统一映射读取
这些配置，数据库、数据分析、材料筛选、异常检测、主控及数据库网页入口也使用
同一读取方法。各助手原有提示词、调用预算和超时不因此改动。

共享配置沿用现有配置加载器：运行环境优先于项目 `.env`。
真实模型入口使用 `INTERN_*`，不会被遗留 `AGENT_BASE_URL` 或 `AGENT_MODEL`
悄悄改成另一个服务。无真实模式/API凭据时的模拟路径保持不变。

全文提取默认使用共享 `INTERN_MODEL`，不再默认选另一个 mini 模型。
明确设置的 `LITERATURE_EXTRACTION_MODEL` 仍优先，只覆盖全文模型名称，不改变
共享服务地址；空值回退共享模型。该项在环境和 `.env` 中都可读取。
全文调用与保存的模型标识使用同一选择规则，命令行全文入口亦采用相同默认规则。

普通助手遵循共享思考模式配置；网页明确选择的思考模式仍有效。
全文结构化提取仍保持原有关闭思考模式的行为，本轮没有猜测实验室兼容性或
删除请求参数。是否需要省略或改变 `thinking_mode` 必须单独验证。
